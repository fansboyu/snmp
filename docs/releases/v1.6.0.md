# netlooker v1.6.0

本版本从 v1.5.5 升级，整合端口流量分析、常用端口关注、邮件配置、采集调度及离线部署。

## 新增与改进

- 独立端口详情：端口切换、业务备注、入/出速率和利用率、历史趋势、相关告警、错误/丢弃累计指标。
- 设备页原位三列关注端口卡片：批量选择、详情和表格同步、本地浏览器持久化、跨标签页同步；只为已关注端口请求迷你趋势，最多三个并发。采集诊断折叠后按需加载。
- Counter64 精确差值计算；按实际采样时间计算速率，区分缺失、重置和过期样本。数据过期时当前速率显示为空，保留趋势断点。
- 邮件配置界面：SMTP、TLS 模式、收件人及恢复通知可配置；数据库保存加密的 SMTP 密码，空密码保留原值，支持明确清除。
- 采集器按设备独立调度，固定工作池、同设备互斥、总耗时预算、失败退避、配置刷新与取消。邻居低频采集，存储保护、聚合和清理在独立维护循环串行执行。
- 工业风网络数据流 SVG Logo，用于侧栏、登录页和浏览器图标。
- Windows x64 离线发布包：七个固定版本镜像、Compose、安装/启停/状态脚本、数据库备份恢复、旧备份转换、文件校验和版本清单。
- 根目录运行配置改为 .env.example；真实 .env 不再随新版本源码发布。本机原文件保留。
- 更新现有版本范围内的 Fastify 路由及 Vue/Vite/ECharts 等依赖，修复 npm 已知风险报告；API 和前端 npm audit 均为零报告。

## 数据库升级

新增迁移 005_email_notification_config.sql 与 006_port_detail.sql。升级前备份数据库和原配置。启动迁移容器成功后再启动应用；不要删除 PostgreSQL 数据卷。

从旧离线部署升级：将原 .env 复制到新版本目录，保留项目名、数据库密码、JWT_SECRET，仅将 IMAGE_VERSION 修改为 1.6.0；运行 install.ps1、start.ps1、status.ps1。同一项目名继续使用原数据库卷。

从源码运行：复制 .env.example 为 .env；已运行环境保留原配置，随后 docker compose up -d --build。

邮件密码使用 JWT_SECRET 派生密钥加密，因此迁移数据库时必须保留对应原密钥。管理员已修改的登录密码以数据库中的记录为准。

## 离线包

发布附件 netlooker-1.6.0-windows-amd64.zip 包含全部运行镜像，不包含当前生产数据库、账号配置或 Docker/WSL 安装程序。目标电脑需预先具备 Docker Desktop Linux containers / WSL 环境以及 Compose 2.20+。

应用安装和启动无需公网拉取镜像；采集设备需要局域网连通，发送邮件需要 SMTP 可达。关注记录仍为浏览器本地收藏，不随数据库备份跨电脑同步。

## 验证

- Go 全包测试、竞态检测及 go vet。
- Node 邮件配置和端口流量计算测试，API 与迁移入口语法检查。
- Vue TypeScript 检查及生产构建。
- Docker 完整采集链路、端口界面、关注同步和空状态验证。
- Windows PowerShell 5.1 离线包安装、首次建库、备份导入、跨项目恢复、邮件密码解密、停止重启与网页验证。

当前仍使用单采集器实例，没有实现多采集器设备租约。本版未做数百台设备容量压测，采集预算和保留策略需根据实际规模配置。
