# v1.6.9

## Highlights

- **Device configuration backups over SSH:** add per-device read-only backup profiles for Cisco IOS, Huawei VRP, and H3C Comware. NETCONF has an adapter interface reserved for a future implementation and is not active in this release.
- **Encrypted version history:** store running configuration content and SSH credentials using AES-256-GCM; compare versions with secret-value redaction and retrieve a selected raw configuration through an audited download.
- **Scheduled and manual jobs:** run independent of SNMP polling with bounded concurrency, stale-job recovery, and up to three attempts. Configure schedule and per-device version retention in the new Configuration Backups page.
- **SSH trust checks:** require a configured SHA256 host-key fingerprint and reject mismatches. The backup client does not write configuration to network devices.

## Upgrade notes

Migration `015_device_config_backups.sql` creates the backup profile, job, encrypted version, and audit tables. Back up PostgreSQL and the deployment configuration before upgrading. The migrator applies the additive schema migration when the new stack starts.

The API and collector must use the same `JWT_SECRET`; the release derives its encryption key from this value. Keep it stable and protected. Changing it makes stored SSH credentials and existing backups undecryptable. The deployment package does not include device credentials or database data.

For Linux/WSL source deployments, the online upgrade script defaults to `v1.6.9`; see [upgrade instructions](../../deploy/upgrade-source-使用说明.md). Existing deployments should preserve the PostgreSQL 18 volume and Compose project name. Do not run `docker compose down -v`.

## Scope and limitations

This release backs up the running configuration only. It does not restore or push configuration, run arbitrary CLI commands, support NETCONF, Telnet, SCP/SFTP, or enable-password escalation. Confirm platform command behavior and access using a read-only account on each target model before enabling scheduled jobs.

## Verification

Validated with API unit and database integration tests on PostgreSQL 18, Go package and race tests, frontend production build, and Docker image builds for API, migrator, collector, and web UI.
