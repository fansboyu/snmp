# v1.6.12

## SNMP collection integrity and diagnostics

- Persist per-device, per-metric collection status, checked time, last successful time, item count, OID and failure/unsupported reason.
- Expose read-only diagnostic endpoints: `GET /api/metrics/snmp-status?deviceId=...` and `GET /api/metrics/interface-identity-changes?deviceId=...`.
- Discard partial interface rows and metadata when both BulkWalk and fallback Walk fail; aggregate walk metrics also discard incomplete data.
- Record changes to an interface's observed `ifName`/`ifDescr` for review instead of silently losing the mapping transition.
- Preserve existing traffic safeguards for counter resets, discontinuity, 32-bit wrap ambiguity, excessive sample gaps and implausible rates.

Migration `017_snmp_collection_diagnostics.sql` is additive. The new diagnostic endpoints require migration 017 to have run.
