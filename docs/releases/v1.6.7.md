# v1.6.7

本补丁修复 LLDP 邻居发现读取二进制 Port ID 时，非法 UTF-8 写入 PostgreSQL 导致拓扑快照事务回滚的问题。无需数据库迁移，继续使用 PostgreSQL 18 和现有数据卷。

## LLDP 端口标识

- 根据 LLDP Port ID subtype 解析 MAC 地址和网络地址；MAC 地址以标准冒号分隔文本保存。
- 对未知或非文本的 OCTET STRING 使用 `hex:` 编码，避免非法 UTF-8 或 NUL 字节进入 PostgreSQL 文本字段，同时保留原始字节信息。
- 有效 UTF-8 标识保持原样。

## 验证

- `go test ./...` 与 `go build ./...` 通过。
- 在本机 Containerlab 环境对 4 台实验设备执行立即邻居采集，LLDP 均成功，共保存 8 条邻居记录，并生成 4 条自动发现拓扑链路。
- 修复后未观察到 PostgreSQL 非法 UTF-8 错误。

## 升级

备份数据库和部署配置后，获取 v1.6.7 源码，在原 Compose 项目目录重建并启动应用：

```bash
git fetch --tags
git checkout v1.6.7
docker compose build collector-go
docker compose up -d --no-deps collector-go
docker compose ps
```

此修复不新增数据库迁移。确认采集器容器正常后，可在拓扑发现页面对设备执行立即采集，并确认 LLDP 扫描成功。
