# v1.6.4

从 v1.6.3 升级一个补丁版本，发布此前本地验证的拓扑展示与 UI 改造。PostgreSQL 仍为 18，沿用现有部署和数据卷。

## 改动

- 登录页和控制台侧栏显示版本号，构建时读取前端 package.json；折叠菜单后仍显示版本数字。
- 拓扑支持指定根节点、按分支分配空间的分层布局、设备类型 SVG 卡片、正交圆角连线和两端端口标签。环路、并行连接及不连通设备保留，锁定位置不被自动布局覆盖。
- 增加分支折叠、搜索定位、到根节点的展示路径高亮、小地图、按缩放显示细节与浮动详情。折叠不改变后台监控或告警。
- 资产类型、厂商、型号支持人工维护并标注来源；接口概览包括逻辑接口，不冒充物理面板。未知型号不自动编造。
- 连接可人工归档为历史并恢复；默认主图隐藏历史连接，归档记录保留证据，不参与当前层级与聚合状态。
- “流动效果”默认开启，正常链路且有新鲜有效速率时，蓝色短线 A→B、青色短线 B→A；零流量、过期、异常或历史连接不播放，编辑模式和隐藏标签页暂停。动画速度固定，仅作方向示意，不是逐包回放；尊重系统减少动态效果偏好。

## 数据库迁移与更新

新增 `010_topology_presentation.sql`：根节点、节点资产展示字段，以及连接 lifecycle/归档时间/原因。支持从 v1.6.3 增量升级；更早版本会按顺序执行已有迁移。

先备份数据库、.env 和 Compose 配置，沿用原项目名和数据卷。不要运行 seed 或 `docker compose down -v`。

```bash
docker compose build
docker compose run --interactive=false -T --rm --no-deps migrator
docker compose up -d
docker compose restart web-vue3
docker compose ps
curl --fail http://localhost:15173/health
```

请在升级后的 API 启动前完成迁移。重建 API 后重启 Web，使 Nginx 使用当前容器地址。检查登录页/侧栏 v1.6.4、设备与历史流量、拓扑根节点和端口绑定。

详细操作和 API 见 [拓扑分层展示说明](../拓扑分层展示说明.md)。物理端口精确映射、厂商型号自动识别及超大规模容量仍需后续适配；展示路径不表示实际路由路径，归档不表示采集器已证实线路拆除。

## 验证与交付

验证包括布局及数据库接口回归、前端类型检查与构建、模拟园区页面操作、流动效果方向/开关/零流量/过期/异常检查，以及本机 Docker 健康和页面检查。模拟数据只在隔离演示库中使用。

本次发布源码、v1.6.4 标签及 Release 说明。旧版本离线附件不覆盖；如需离线安装包，应基于 v1.6.4 标签重新构建，不能将旧包改名当作新版本。
