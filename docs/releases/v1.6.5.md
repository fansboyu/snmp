# v1.6.5

本版改善网络监控前端的图标识别与视觉一致性。PostgreSQL 仍为 18；无数据库结构或采集逻辑变更。

## 改动

- 为拓扑设备类型提供统一风格的 SVG 图形，并在设备类型选择器中展示对应图标。
- 设备列表增加设备图形；仪表盘、告警、设备详情和端口详情指标卡增加语义化图标。
- 拓扑与自动发现空状态增加网络主题插图，图标资源随前端本地交付，不依赖运行时外网请求。
- 新增的 Tabler 图形按 MIT License 分发，许可文本随资源保留在 `web-vue3/public/icons/TABLER-LICENSE.txt`。

## 更新

本版只涉及前端展示与版本号，不需要数据库迁移。使用源码 Compose 部署时，更新源码后重建并启动 Web 服务：

```bash
docker compose build web-vue3
docker compose up -d web-vue3
docker compose ps
curl --fail http://localhost:15173/health
```

前端生产构建通过；本机 Docker Web 容器健康，拓扑插图和设备 SVG 可正常加载。发布不包含离线镜像 ZIP；如需离线安装包，应从 v1.6.5 标签单独构建。
