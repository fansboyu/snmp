# 拓扑分层展示

本次改造随 v1.6.4 发布，保留现有设备、端口、采集、告警和通知功能，扩展默认拓扑的展示与配置；不新增常驻容器。

## 使用步骤

1. 进入网络拓扑，默认显示完整画布。点击设备或连接打开右侧浮动详情，关闭后恢复完整画布。
2. 进入编辑模式，通过根节点选择框指定出口或核心。清空表示自动选择；未知邻居不会优先于已知核心作为根。
3. 点击自动布局预览，检查后保存。布局依据连接构建分层展示树，父节点尽量居中，分支按所需空间排列。不连通设备独立摆放；环路、跨层、并行和冗余连接继续保留。根节点影响阅读顺序，不代表实际路由方向。
4. 锁定节点保持原坐标；锁定导致的局部不对称是保护人工布局的结果。状态更新不重新排版。
5. 点击有下属分支的设备可折叠/展开；卡片提示隐藏数量与离线/采集异常数量。折叠仅影响当前浏览，隐藏连接与设备仍接受监控。可一键展开所有分支。
6. 按名称/IP 搜索并点击定位设备，将展开分支、清除筛选并居中选中设备。可高亮它到根的展示路径；这不是实际转发路径，其他上联保留。
7. 小地图显示当前可见拓扑和视口，点击可移动画布。Ctrl/Command 加滚轮缩放，适配视图恢复总览。缩小时省略型号、IP、接口细节和端口标签，放大后显示。
8. 默认查看连接状态，流量模式按需加载速率。两端端口标签分别靠近各端点，未绑定时明确显示待确认，不推断端口名称。

9. “流动效果”默认开启，正常链路且参考端口采样新鲜、对应方向速率大于零时显示移动短线：蓝色从 A 到 B（A 出），青色从 B 到 A（A 入）；仅有 B 端采样时反向换算。未知、过期、零流量、异常或历史连接不播放。动画速度固定，只是采样速率方向示意，不是逐包回放。编辑模式、隐藏浏览器标签页以及系统减少动态效果偏好下暂停；可单独关闭，不影响流量数字和状态颜色。

## 设备卡片与资产

支持通用设备、路由器、交换机、防火墙、AC、AP、云与未知设备 SVG 图标。编辑面板可以指定图标类型、厂商、型号，来源标为人工维护；未提供可靠识别结果时使用通用图标、类型名称或待补充提示，不编造设备型号。

接口概览复用已有接口表，包含逻辑接口，并标明数据是否过期。它不是物理设备面板，也不宣称端口序号对应实际机箱位置。精确型号自动识别和物理端口映射仍需后续厂商适配。

## 历史连接

编辑模式中选中连接，可以人工归档，默认从主图隐藏；勾选显示历史连接后以灰色虚线查看，并可恢复。归档保留端口与邻居证据，不因普通刷新重新变为当前连接；仍观察到相同物理标识时也不自动恢复。历史连接不参与当前层级、聚合状态及当前流量汇总。人工归档不代表采集器已证实线路拆除，过期连接不会被自动删除。

## 数据和接口

迁移 `010_topology_presentation.sql` 添加：

- `topology_maps.root_node_id`：根节点，删除该节点时清空。
- 节点 `asset_kind / asset_vendor / asset_model`：展示资产字段。
- 连接 `lifecycle / retired_at / retired_reason`：当前或历史状态。

沿用原接口，增加：

- `PATCH /api/topology/default/settings`，请求 `{ "root_node_id": "节点编号或null" }`，根必须属于当前拓扑。
- `PATCH /api/topology/links/:id/lifecycle`，请求 `{ "lifecycle": "current或history" }`。
- 节点 settings 接口支持资产字段。默认拓扑返回 `tree`（展示父节点、父连接、层次和根）、节点展示类型/资产来源/接口概览以及连接归档字段。

## Docker 更新与验证

先备份数据库，保留原项目名、环境变量和数据卷，不执行 seed 或 `down -v`：

```bash
docker compose build api-gateway migrator web-vue3
docker compose run --interactive=false -T --rm --no-deps migrator
docker compose up -d
docker compose restart web-vue3
curl --fail http://localhost:15173/health
```

已通过带环路/并行连接/不连通设备的布局测试、接口回归与隔离模拟园区浏览器验证。真实厂商邻居发现和超大规模容量仍需现场验证。模拟节点只存在独立演示数据库，真实监控库不写入演示设备。
