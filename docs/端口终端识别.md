# 交换机端口终端识别

设备端口详情页可显示交换机在端口上学习到的 MAC 地址，以及能够从三层 ARP 表关联到的 IPv4 地址。数据来自 SNMP 观测，不代表端口上一定直连了该终端。

## 采集与关联

1. 对已启用设备读取 Q-BRIDGE-MIB VLAN/FDB/MAC/端口信息；无法获得该表时尝试 BRIDGE-MIB。通过 bridgePort 到 ifIndex 映射关联设备接口。
2. 从支持的三层设备读取 IPv4 ARP 表，获取 IP、MAC、三层接口及最近观测时间。可识别 SVI 名称时记录 VLAN。
3. 按 MAC 和可用 VLAN 关联交换机与三层设备的两侧观测。页面分别显示 VLAN、IP、MAC、IP 来源设备、观测时间和关联可信度。

采集周期沿用拓扑邻居采集周期，默认 10 分钟。页面仅展示最近 30 分钟内的观测；旧观测不会作为当前在线证据。数据库中超过配置保留期的终端观测会分批清理，默认保留 90 天；存储紧急清理默认保留 30 天。

本功能新增迁移 `012_endpoint_observations.sql`；迁移 `014_ip_mac_observation_locations.sql` 保留同一 IP/MAC 在不同 VLAN 或三层接口上的独立证据。执行对应版本的 migrator 后再启动新版采集器。

## 可信度说明

- **VLAN 精确匹配**：交换机 FDB 与 ARP 观测 VLAN 相同，MAC 只出现在一个物理端口位置，且 IP 只有一个 ARP 来源。
- **唯一 MAC 候选**：MAC 位置和 ARP 来源唯一，但缺少可比较的 VLAN 证据。
- **存在歧义**：同一 MAC 出现在多个交换机端口，或 IP/MAC 关系来自多个三层接口。
- **仅发现 MAC**：交换机有 MAC 学习记录，但当前没有可关联的 ARP 记录。

## 网络设备要求与边界

- SNMP 账号需要可读取 Q-BRIDGE-MIB、BRIDGE-MIB、IP-MIB 相关表；厂商 ACL 或 SNMP View 可能隐藏这些表。
- 交换机没有可读 FDB 时，不会推测端口下的 MAC。三层设备没有可读 ARP 表时，只能显示 MAC。
- BRIDGE-MIB 回退表不含 VLAN，结果可信度会降低。SVI VLAN 仅在接口名称可识别时推断。
- 上联口会学习到下游多个终端的 MAC；页面标出可能的上联口，不能据此说终端直接连接该端口。
- 当前 IP 关联使用 IPv4 ARP；IPv6 邻居发现、DHCP 租约和终端身份识别不在本功能范围内。
